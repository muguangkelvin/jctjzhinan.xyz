### 🔗 核心概念与工作链路

理解这三者的核心区别，先看流量从你的本地客户端（Client）到达境外目标服务器（Target）的具体路径：

1. 🌐 **普通直连节点（Direct Connection）**
   - **传输路径**：`本地` → `公网跨国光缆/骨干网` → `境外 VPS 节点` → `目标网站`
   - **运作机制**：用户设备直接发起跨国 TCP/UDP 请求，流量全程通过公网公共信道。虽然节点通常会选用优化线路（如电信 CN2 GIA、联通 9929/AS4837、移动 CMIN2 等），但在高峰期仍需与海量民用流量竞争跨国公网带宽出口。
   - **致命短板**：数据包直接穿过公网跨国边界，容易受到审查阻断、流量干扰或物理海缆拥堵影响，晚高峰容易出现丢包抖动。

2. 🔀 **公网中转节点（Relay / Tunnel）**
   - **传输路径**：`本地` → `国内公网中转服务器` → `跨国公网传输（隧道加密）` → `境外落地服务器` → `目标网站`
   - **运作机制**：用户不直接连境外机器，而是先连接一台国内延迟极低的中转机（如国内 BGP 节点）。国内机与境外机之间通过加密隧道（如 TLS/WebSocket/gRPC 等）传输数据。
   - **优缺点分析**：国内接入延迟低、速度表现通常优于普通直连；但其跨国段依然走的是公网，在特殊时期或高峰时段，两台机器之间的跨国通道依然可能被限速或丢包。

3. ⚡ **IEPL 专线节点（International Ethernet Private Line）**
   - **传输路径**：`本地` → `专线入口端点` → `内网物理/以太网隔离通道（不过公网跨国审查）` → `专线出口落地端点` → `目标网站`
   - **运作机制**：IEPL 属于国际以太网私有专线，基于电信运营商的底层传输网络（如 SDH/MSTP/OTN）搭建。流量在国内接入后，直接进入运营商级别的两地私有二层专线通道内直达境外机房。
   - **核心优势**：
     - 🛡️ **真·不过墙**：流量在专线内网通道内传输，不走公网跨国出口，彻底免除跨国审查干扰与阻断。
     - 🚀 **独享带宽与低抖动**：运营商 SLA 保障，无公网高峰期抢带宽现象，丢包率趋近于 0，延迟极度稳定。

### ⚠️ 常见误区与避坑指南

- ❌ **“中转”不等于“专线”**：
  市面上不少服务商将普通的“国内双程中转”包装为“专线”。识别真伪的关键在于看跨国段是否走公网。如果 ping 测试在晚高峰依然有 10% 以上丢包，或在网络敏感期频繁断连，基本都是普通的公网隧道中转，而非真正的物理专线。

- 🔍 **IEPL 与 IPLC 的细微区别**：
  - **IPLC (International Private Leased Circuit)**：传统点对点物理租用电路，多为 TDM/时分复用二层链路。
  - **IEPL (International Ethernet Private Line)**：基于以太网技术的增强版私网线路，支持以太网接口直接互联，扩展性更好、调度更灵活，但在最终的用户体验（延迟与防丢包）上两者几乎一致。

- ⚡ **入口与出口的限制**：
  专线虽然在跨国段表现完美，但你的设备到国内“入口机”依然走的是本地宽带公网。如果本地 ISP 到专线入口的路由不佳，依然可能在这一段产生延迟。因此选购时应优先选择支持多线 BGP 入口的专线服务。

### 🎯 选型建议

- 💡 **选择直连**：个人轻度学术检索、海外网页浏览，或者预算有限且自身宽带有运营商精品网（如电信 CN2）优待的用户。
- 📺 **选择普通中转**：日常需要观看海外 4K 流媒体、下载大文件，希望兼顾速度与成本效益。
- 🚀 **选择 IEPL 专线**：对连接可用性要求达到 99.9% 的跨国远程协作、高频股票/加密货币行情交易、跨服竞技游戏加速，以及企业出海等核心生产力场景。

### 深入解析：为什么选择稳定的 IEPL专线机场 对于网络体验至关重要？

在搭建和使用海外网络代理时，很多小白用户容易掉入“低价月抛”或“虚标带宽”的坑中。实际上，一个高质量的节点服务，其核心竞争力不在于宣传的“几百个节点”，而在于**真正的公网中转质量与专线冗余**。

#### 1. 线路架构的区别：直连 vs 中转 vs IEPL 专线
- **直连节点 (Direct)**：本地设备直接连接海外 VPS 服务器。受限于国际出口 BGP 路由和墙的封锁，晚高峰丢包率可能高达 30% 以上，延迟剧烈波动。
- **公网中转 (Transit)**：在入口处部署国内中转服务器，将数据打包后通过公网发往出口。稳定性有所提升，但如果中转节点遭遇攻击或污染，依然影响体验。
- **IEPL 内网专线 (International Private Leased Circuit)**：端到端物理专线，数据过境不经过公网防火墙检查，具有**超低延迟、零丢包、绝无封锁风险**的特点。

#### 2. 分流规则与 TUN 模式的工作机制
对于使用 Clash Verge Rev、Sing-box 或 Shadowrocket 的用户来说，合理的分流规则可以实现“国内流量直连、海外流量走节点”。
开启 **TUN (Tunnel) 虚拟网卡模式** 后，系统会将全局网络流量接管至代理内核中。这样即使部分软件（如 Discord、Telegram、Spotify）不支持自定义代理协议，也能无缝通过专线节点完成加速。

#### 3. 购买前注意事项与风险防范
- **按月付费**：任何新用户在使用未知的节点服务时，强烈建议先选择月付套餐，测试本地网络运营商（电信、联通、移动）在晚高峰 20:00-23:00 的实际表现。
- **设备数量限制**：核对套餐支持的最大同时在线设备数，避免家庭多设备在线时触发断连规则。
- **价格与结算**：所有套餐价格、优惠码与流量包规则均可能随运营成本微调，下单前请仔细核对第三方结算页面的最终账单。
