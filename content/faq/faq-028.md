  <p>在网络科学上网过程中，许多用户只关注流量是否经过加密隧道传输，却忽略了极其危险的 <strong>DNS 泄露（DNS Leak）</strong> 风险。当未配置 DNS 防防护时，虽然你的网页内容走的是加密节点，但本地运营商 (ISP) 依然能通过发往 `114.114.114.114` 或运营商本地 DNS 服务的解明文请求，精准追踪到你访问过的每一个海外目标域名。在 <strong>Clash Verge Rev</strong> 中选对 DNS 模式至关重要。</p>

### 📌 一、 问题直接解答

针对【**Clash 的 DNS 泄漏防范设置应该怎么选？**】这一核心安全配置：

- 🏆 **强烈推荐选择 `Fake-IP` 模式**：配合 `enhanced-mode: fake-ip` 与远程 DNS 解析，能够在物理层面 100% 杜绝本地 DNS 泄露，同时消除 DNS 解析造成的连通延迟。
- ❌ **不推荐选用传统的 `redir-host` 模式**：`redir-host` 会在本地发起真实 DNS 解析，容易遭受国内 ISP 的 DNS 劫持与污染，并将你的访问历史暴露给本地运营商。

<br>

### 📊 二、 Fake-IP 与 redir-host 模式深度横向对比

| 对比维度 | Fake-IP 模式 (推荐) | redir-host 模式 (传统) |
|:---|:---|:---|
| **DNS 泄露防护** | **100% 防泄露 (本地不发起真实 DNS)** | 容易发生 DNS 泄露与污染 |
| **首包响应延迟** | **零延迟 (瞬间返回 198.18.x.x 虚假 IP)** | 需等待 DNS 解析返回 (增加 100~300ms) |
| **域名分流准确率** | **极高 (由远程节点统一解析)** | 受本地 DNS 污染影响容易分流错误 |
| **旧款游戏/联机兼容性** | 极少数依赖真实 IP 的硬编码游戏需例外规则 | 兼容性略高 |
| **推荐适用场景** | 全平台日常使用、AI 办公、流媒体防锁区 | 仅用于特殊老旧设备排错 |

<br>

### 🛡️ 三、 防范 DNS 泄露的 3 大最佳配置实践

在 Clash Verge Rev 的订阅或 Mixin 设置中，请按以下参数优化 `dns` 配置：

```yaml
dns:
  enable: true
  prefer-h3: true # 开启 HTTP/3 QUIC 高速 DNS 查询
  listen: 0.0.0.0:53
  enhanced-mode: fake-ip
  fake-ip-range: 198.18.0.1/16 # 保留的虚假 IP 地址池
  nameserver:
    - https://dns.alidns.com/dns-query # 阿里加密 DoH (国内直连)
    - https://doh.pub/dns-query        # 腾讯加密 DoH (国内直连)
  fallback:
    - https://1.1.1.1/dns-query        # Cloudflare 加密 DoH (海外节点)
    - https://dns.google/dns-query     # Google 加密 DoH (海外节点)
```

### 🔍 四、 如何测试你的网络是否存在 DNS 泄露？

1. 保持 Clash Verge Rev 系统代理或 TUN 模式处于开启状态；
2. 在浏览器中打开国际通用的 DNS 泄露测试网站：`https://www.dnsleaktest.com`；
3. 点击 **Standard Test** 或 **Extended Test**；
4. 查看测试结果中的 IP 服务器列表：
   - 🟢 **安全无泄露**：只显示美国、香港、日本等海外节点的 DNS 服务器，无中国大陆 ISP（如中国电信、中国联通）标记。
   - 🔴 **存在泄露**：列表中出现了你所在城市的国内运营商 IP，需立刻切换为 `fake-ip` 模式并启用 DoH 加密。
