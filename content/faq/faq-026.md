### 📌 一、 问题直接解答

针对【**Clash 混合配置 (Mixin) 和预处理 (Script) 怎么用？**】这一高阶需求：
- 🟢 **Mixin (混合配置)**：适合静态覆盖简单属性（如全局追加 DNS、更改本地 SOCKS5/HTTP 端口 `7890`、强制开启 TUN 模式）。
- 🚀 **Script (预处理脚本)**：适合使用 JavaScript 编写动态逻辑，自动筛选节点、为多个订阅动态插入 `OpenAI`、`Netflix` 独立策略组及高级正则过滤。

<br>

### 🛠️ 二、 Mixin (混合配置) 语法与一键模版

Mixin 允许你编写全局生效的 YAML 语言片段，无论切换哪个机场订阅，Mixin 的规则都会优先级最高合并进去。

#### 实用 Mixin 静态模板（追加自定义 DNS 与全局规则）：

```yaml
# 在 Clash Verge Rev -> 订阅 (Profiles) -> Mixin 中开启并编辑
mixin:
  dns:
    enable: true
    enhanced-mode: fake-ip
    nameserver:
      - 223.5.5.5
      - 119.29.29.29
      - https://dns.alidns.com/dns-query
  rules:
    # 强制让特定的私有办公域名走直连
    - DOMAIN-SUFFIX,company-internal.com,DIRECT
    # 强制让特定 AI 工具走专线策略组
    - DOMAIN-KEYWORD,openai,Proxy
    - DOMAIN-KEYWORD,anthropic,Proxy
```

<br>

### 💻 三、 Script (预处理脚本) 动态处理逻辑

如果需要针对不同机场的特殊节点命名（如过滤包含“过期”、“流量”字的节点），可以使用 JavaScript 预处理脚本：

```javascript
// 在 Clash Verge Rev -> 预处理 (Merge/Script) 中新建脚本
function main(config, profileName) {
  // 1. 过滤掉包含 '过期' 或 '0.0x' 费率的测试节点
  if (config.proxies) {
    config.proxies = config.proxies.filter(p => !p.name.includes("过期") && !p.name.includes("官网"));
  }
  
  // 2. 动态插入独立的 AI 办公策略组
  if (config['proxy-groups']) {
    config['proxy-groups'].unshift({
      name: 'AI 办公专用',
      type: 'select',
      proxies: ['SG-专线', 'US-专线', 'DIRECT']
    });
  }
  
  return config;
}
```

<br>

### ⚠️ 四、 Mixin 与 Script 使用注意事项与排错

1. ⚠️ **YAML 缩进严格性**：Yaml 语法使用两个空格缩进，严禁使用 `Tab` 缩进，否则导入时报 `yaml: line X: did not find expected key` 错误。
2. 🔄 **覆盖优先级机制**：在 Clash Verge Rev 的合并顺序中：`原机场订阅` < `Script 脚本预处理` < `Mixin 混合配置` < `系统设置快捷开关`。
3. 🐞 **语法调试方法**：编写完脚本后点击右下角 **运行测试 (Test)** 按钮，在控制台查看 JSON 输出格式是否合规。
