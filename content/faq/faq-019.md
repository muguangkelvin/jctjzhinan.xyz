### 📌 一、 问题直接解答

针对【**Clash Verge Rev 如何导入订阅链接？**】这一核心操作，操作流程仅需 30 秒：**复制机场后台 Clash 订阅 URL -> 打开软件订阅 (Profiles) 面板 -> 粘贴链接并点击导入 -> 选中新配置并开启系统代理或 TUN 模式。**

<br>

### 🛠️ 二、 Windows 与 Mac 端导入 4 步图文全流程

1. 📋 **第一步：复制机场订阅链接**
   - 登录您购买的机场服务商后台仪表盘。
   - 在“订阅接入”或“一键导入”区域，找到 **复制 Clash 订阅链接**（或通用订阅地址），点击复制到系统剪贴板。

2. 📥 **第二步：打开 Clash Verge Rev 添加配置**
   - 打开 Clash Verge Rev 客户端，点击左侧导航栏的 **订阅 (Profiles)** 选项。
   - 在顶部文本框中粘贴刚才复制的订阅 URL 链接。
   - 可选：在右侧自定义配置备注名称（如“灵动云专线”）。

3. ⚡ **第三步：点击导入并拉取节点**
   - 点击右侧的 **导入 (Import)** 按钮，软件会自动发起网络请求拉取节点的 YAML 配置文件。
   - 导入成功后，列表中会出现对应卡片，并显示节点总数与更新时间。

4. 🔀 **第四步：激活配置并开启连接**
   - 单击刚导入的配置卡片，使其左侧出现高亮色块（代表当前激活此配置）。
   - 切回左侧 **代理 (代理/Proxies)** 面板，选择策略组模式（推荐选择 **Rule / 规则** 模式）。
   - 切回 **设置 (Settings)**，开启 **系统代理 (System Proxy)** 或 **TUN 模式** 即可开始流畅翻墙。

<br>

### 🚨 三、 订阅导入失败（Fetch Profile Failed）4 大故障排查

若点击导入后弹出 *“Fetch Profile Failed”* 或 *“Network Timeout”* 报错，请检查：

- ❌ **原因一：原机场链接包含特殊字符或需要转换**：部分老旧机场提供的订阅为纯 base64 或 V2Ray 格式，需通过 Subconverter 转换前端选择 `Clash` 目标格式后再导入。
- ❌ **原因二：本地开启了旧版代理导致冲突**：请关闭系统其他旧客户端（如 v2rayNG、Clash for Windows），避免端口冲突。
- ❌ **原因三：运营商 DNS 拦截**：在 Clash Verge Rev 设置中将应用 DNS 改为 `223.5.5.5` 或 `1.1.1.1` 后重试。
- ❌ **原因四：套餐到期或账户受限**：登录机场官网检查套餐流量是否耗尽或订单是否过期。

<br>

### 🔄 四、 开启自动定时刷新订阅

为保证服务商更新节点 IP 或维护线路时能够同步，建议开启自动刷新：
- 在 **订阅 (Profiles)** 面板中右键点击配置卡片；
- 选择 **编辑信息 (Edit)**；
- 设置 **更新间隔 (Update Interval)** 为 `1440` 分钟（即 24 小时自动定时轮巡更新）。
