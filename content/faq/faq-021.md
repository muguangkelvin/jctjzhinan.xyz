### 📌 一、 问题直接解答

针对【**Clash 开启 TUN 模式后无网络连接怎么办？**】这一高频故障，标准修复流程为：**安装服务模式 (Service Mode) 获得管理员特权 -> 清理残留废弃的 WinTun 网卡驱动 -> 检查本地系统 DNS 是否与 `dns-server` 冲突 -> 在防火墙中放行 Clash 进程入站/出站权限。**

<br>

### 🔍 二、 导致 TUN 模式无网络连接的 4 大根源与解决方案

#### 1. 服务模式 (Service Mode) 未安装或缺乏特权
- ❌ **故障原因**：TUN 模式需要在系统底层创建虚拟网卡（TAP/TUN Device），必须拥有操作系统最高管理员特权。
- 🛠️ **解决办法**：
  - 在 Clash Verge Rev 中点击 **设置 (Settings)** -> **服务模式 (Service Mode)**；
  - 点击 **安装 (Install)** 按钮，安装系统常驻服务，成功后显示绿色 `Active` 标志；
  - 重启客户端后再勾选开启 **TUN 模式**。

#### 2. WinTun 虚拟网卡驱动冲突与设备残留
- ❌ **故障原因**：以往安装过旧版 Clash、Sing-box、VPN 或 VirtualBox 虚拟机，导致网络适配器中残留了坏损的 `wintun` 虚拟网卡。
- 🛠️ **解决办法**：
  - 按下 `Win + X` 键，选择 **设备管理器 (Device Manager)**；
  - 展开 **网络适配器 (Network adapters)**；
  - 找到带感叹号或多余的 `WinTun` / `Clash TUN` 设备，右键选择 **卸载设备 (Uninstall)**；
  - 在 Clash Verge Rev 中关闭并重新开启 TUN 模式，软件会自动重新生成干净的网卡驱动。

#### 3. DNS 服务器冲突与死循环解析
- ❌ **故障原因**：配置文件的 `dns` 节点开启了 `fake-ip` 模式，但上游 DNS 设置错误或被本地杀毒软件劫持。
- 🛠️ **解决办法**：
  - 检查配置文件或 Mixin 设置，确保 `dns` 节点包含合规的上游解析服务：
    ```yaml
    dns:
      enable: true
      enhanced-mode: fake-ip
      nameserver:
        - 223.5.5.5
        - 119.29.29.29
        - 1.1.1.1
    ```

#### 4. Windows Defender / 杀毒软件防火墙拦截
- ❌ **故障原因**：360 安全卫士、火绒或 Windows Defender 防火墙拦截了虚拟网卡流量转发。
- 🛠️ **解决办法**：
  - 前往“控制面板 - 系统与安全 - Windows Defender 防火墙”；
  - 点击“允许应用通过防火墙”，将 `clash-verge.exe` 与 `clash-meta.exe` 勾选允许公用和专用网络访问。

<br>

### 📋 三、 TUN 模式故障排查自检 5 步清单

- [ ] 检查 **Service Mode** 是否处于 `Active` 运行状态；
- [ ] 检查设备管理器中 **WinTun** 虚拟网卡驱动无报错感叹号；
- [ ] 检查控制面板“网络和共享中心”，TUN 网卡是否已获取 `198.18.0.1` 内部 IP；
- [ ] 关闭第三方杀毒软件测试网络连通性；
- [ ] 尝试在 TUN 设置中将网卡堆栈由 `gVisor` 切换为 `System` 模式后重启。
