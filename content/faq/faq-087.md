### 🛠️ 三、 核心软件安装与配置实操

#### 1. Clash Meta for Android (CMA) 配置步骤
- 📥 **下载安装**：推荐从 GitHub Releases 官方下载最新的 `.apk` 安装包。
- 🔗 **导入订阅**：打开 CMA，点击 **配置 (Profiles)** -> **新配置** -> **URL**，粘贴机场复制的 Clash 订阅链接，点击右上角保存。
- ⚡ **开启连接**：选中刚才下载的配置，切回主页点击 **已停止** 开关。首次启动时系统弹出“允许创建 VPN 连接”，点击 **确定**。

#### 2. Sing-box for Android 配置步骤
- 📥 **下载安装**：前往 Google Play 商店或 GitHub 发布页下载 Sing-box 官方包。
- 🔗 **导入 Profile**：打开软件，进入 **Profiles** 面板，点击 `+` 号 -> 选择 **Remote**，粘贴 Sing-box 专属订阅链接并保存。
- 🔀 **开启 TUN 模式**：进入 **Dashboard**，勾选 Profiles 后打开主开关，确认授权 VPN 系统接口。

### 🔋 四、 安卓手机防后台杀进程排错 4 步骤

由于国内 Android 厂商系统（如小米 HyperOS、华为鸿蒙、vivo OriginOS、OPPO ColorOS）内存管理极其严格，开启代理后台运行一段时间后可能会被系统自动清理，导致突然断网。请进行以下优化：
1. 🔒 **后台任务锁**：打开多任务后台界面，长按 Clash Meta 或 Sing-box 窗口，点击 **锁定 (Lock)** 图标。
2. 🔋 **无限制电池优化**：进入手机“设置 - 应用管理 - 电池优化/省电策略”，将客户端设置为 **无限制 (Unrestricted)** 或 **允许后台高耗电**。
3. 🚀 **允许自启动**：在应用权限管理中勾选 **允许自动启动** 与 **允许关联启动**。
4. ⚙️ **常驻通知栏**：在软件设置中勾选 **常驻通知栏提示**，保持 Android 系统 Service 优先级。
