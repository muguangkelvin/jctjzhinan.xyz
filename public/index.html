新手常问问题解答 (FAQ)

选选选、购购购、用用用全流程疑难排错。

Q: 新手小白第一次选机场，应该看重哪些核心指标？

A: 建议重点看 4 个维度：① 线路架构（优先选择 IEPL / IPSLC 专线，抗封锁且晚高峰延迟低）；② 计费与付款周期（建议先按月付费或选低成本年付试用）；③ 客户端兼容性（是否支持一键导入或主流 Clash/Sing-box 订阅）；④ 客服与文档支持。避免一次性购买不了解的长期高额套餐。

Q: IEPL 专线与直连/公网中转节点有什么区别？

A: IEPL（International Private Leased Circuit）是端到端内网专线，数据不经过公网 GFW 审查，延迟极低且绝不会遭遇封锁断连；而直连或普通公网中转容易在晚高峰丢包抖动，甚至被墙。对于追求稳定的用户，首选 IEPL 专线机场。

Q: 为什么导入订阅后显示 0 个节点或提示更新失败？

A: 常见原因包括：① 订阅 URL 复制缺失或带有空格；② 本地网络限制了订阅域名访问（可尝试更换本地网络或开 TUN 模式重试）；③ 机场订阅链接被运营商污染，需在机场后台使用备用订阅转换域名；④ 软件版本过旧不支持新的协议格式。

Q: 开启 TUN 模式或代理后，本地软件（如微信、钉钉）无网络怎么办？

A: 这是由于 TUN 虚拟网卡劫持了系统全量流量，且分流规则未正确设置。请检查 Clash / Sing-box 的规则配置，确保勾选了“绕过大陆 IP”（Bypass Mainland / China Domain）或启用系统的 Rule 规则分流模式。

Q: 为什么同一个机场，看视频速度快但登录 ChatGPT / Claude 会报错？

A: OpenAI 对节点 IP 的风控级别极高，如果过多用户共用同一个出口 IP，该 IP 就会被标记为 Cloudflare 机器人或数据中心 IP 遭封禁。建议使用针对 AI 工具优化或原生住宅 IP 节点，并开启规则分流。
